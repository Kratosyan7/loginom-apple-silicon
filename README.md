# Loginom Community на Apple Silicon

Loginom Community выпускается для Windows и Linux. Сборки под macOS нет, а Linux-версия —
бинарник под x86-64, который на процессорах Apple не запускается.

Здесь лежит обвязка, которая решает проблему: Linux-контейнер на arm64, где вся
инфраструктура работает нативно, а само приложение транслируется через
[box64](https://github.com/ptitSeb/box64). Интерфейс открывается встроенным
в macOS «Общим экраном».

## Чего здесь нет

**Файлов самой программы.** Их распространение запрещено лицензией Loginom (п. 5.5 и 5.8),
поэтому дистрибутив нужно скачать самостоятельно — это бесплатно.

## Установка

Нужен [Docker Desktop](https://www.docker.com/products/docker-desktop/).

```bash
git clone https://github.com/Kratosyan7/loginom-apple-silicon.git
cd loginom-apple-silicon
```

Скачайте Linux-версию Loginom Community с [loginom.ru/community](https://loginom.ru/community),
положите архив в эту папку и распакуйте:

```bash
tar -xf loginom-community-*.tar.gz
./run.sh
```

Первый запуск собирает образ — это 5–10 минут. Дальше контейнер стартует за секунды.
Повторные запуски — тот же `./run.sh`.

## Как пользоваться

| | |
|---|---|
| Подключение | `vnc://localhost:5900` |
| Пароль | `loginom` |
| Общая папка | `~/Loginom` на маке ↔ `Данные` в Loginom |

Окно остаётся белым первые 60–90 секунд после запуска, пока инициализируется
встроенный браузерный движок. Это не зависание.

Чтобы открыть свой файл, положите его в `~/Loginom` — в диалоге выбора файла он будет
в разделе **«Данные»** слева.

Буфер обмена работает в обе стороны: копируете на маке через ⌘C, вставляете
в Loginom через **Ctrl+V** (внутри Linux именно Ctrl, не ⌘).
